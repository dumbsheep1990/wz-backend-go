# 用户收藏服务DDD架构设计

## 1. 概述

用户收藏服务是WZ系统中的核心服务之一，负责管理用户对各类内容的收藏操作，包括收藏、取消收藏、查询收藏列表和统计等功能。本文档描述了使用领域驱动设计(DDD)对该服务进行的架构设计。

## 3. 领域模型

### 3.1 核心概念

- **收藏记录(UserFavorite)**: 表示用户收藏的一个内容项
- **内容类型(ItemType)**: 区分不同类型的收藏内容，如文章、商品、视频等
- **热门内容(HotContent)**: 被多个用户收藏的热门内容
- **收藏趋势(Trend)**: 一段时间内收藏数量的变化趋势

### 3.2 聚合根

- **UserFavorite**: 用户收藏聚合根

### 3.3 值对象

- **ID**: 唯一标识符
- **UserID**: 用户标识符
- **ItemID**: 内容项目标识符
- **ItemType**: 内容类型值对象
- **Title**: 标题值对象
- **URL**: URL值对象
- **TenantID**: 租户ID值对象

### 3.4 领域事件

- **UserFavoriteCreatedEvent**: 用户收藏创建事件
- **UserFavoriteDeletedEvent**: 用户收藏删除事件

## 4. 领域规则

1. 用户不能重复收藏同一内容项
2. 收藏的标题和内容类型不能为空
3. 删除收藏只能由收藏创建者或管理员操作
4. 内容类型必须是系统支持的预定义类型
5. 收藏记录一旦创建，只能更新备注等部分字段，不能修改核心字段如内容ID、类型等
6. 批量操作（如批量删除）需要验证每个操作的权限

## 5. 应用服务

**UserFavoriteApplicationService** 负责协调领域对象和基础设施，提供以下功能：

1. 创建收藏记录
2. 获取收藏记录详情
3. 获取用户收藏列表
4. 删除收藏记录
5. 批量删除收藏记录
6. 检查内容是否已被收藏
7. 获取收藏统计数据
8. 获取热门收藏内容
9. 获取收藏趋势数据
10. 导出收藏数据

## 6. 基础设施

1. **仓储实现**: 使用SQL数据库存储收藏记录
2. **事件总线**: 发布和订阅领域事件
3. **工作单元**: 管理事务，确保操作的原子性

## 7. 接口层

提供HTTP API，包括：

1. 获取用户收藏列表
2. 创建收藏记录
3. 获取收藏记录详情
4. 删除收藏记录
5. 批量删除收藏记录
6. 检查是否已收藏
7. 获取收藏统计数据
8. 获取热门收藏内容
9. 获取收藏趋势数据
10. 导出收藏数据

## 8. 设计决策

1. **使用充血模型**: 将业务规则封装在领域对象中，使其具有行为而不仅是数据容器
2. **值对象不可变**: 确保值对象创建后不可修改，提高系统的稳定性
3. **领域事件通知**: 使用事件机制实现系统各部分的松耦合集成
4. **工作单元管理事务**: 确保领域操作的原子性和一致性
5. **仓储依赖抽象**: 通过接口定义仓储，实现基础设施与领域的分离
